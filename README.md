# Espacio Seguro · Portal contra el ciberacoso

Sitio estático (HTML, CSS y JS puro, sin dependencias) con información y un canal de reporte para estudiantes, familias y docentes.

## Archivos
`index.html`, `style.css`, `script.js`, `hero.svg` (ilustración), `favicon.svg`, `favicon.ico` y `apple-touch-icon.png` (íconos). Sube todos a la misma carpeta.

## Personalizar
Edita el bloque `CONFIG` al inicio de `script.js`: nombre del colegio, correo que recibe los reportes y contacto de orientación. Verifica también las líneas de ayuda en `index.html`.

## Publicar en GitHub Pages
1. Sube estos archivos a un repositorio (en la raíz).
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. En unos minutos tendrás el sitio en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Nota sobre los reportes
El formulario abre el correo del usuario con el mensaje listo; no almacena datos. Para un buzón realmente anónimo, conecta un servicio de formularios (p. ej. Formspree o Google Forms) y coordina con el comité de convivencia.
